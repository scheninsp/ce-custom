
## 二、第四节可以直接补充的证据

### 1. 价格函数缺失项：当前只能补齐“调用前后位置”

原第四节要求完整导出 `+1408330`、`+13A3280`、`+13A3B10`、`+13A5280`。现有静态导出已经确认：`+140A6B0` 会调用 `+1408330`，再经过 `+13A3280`、`+13A3B10`、`+13A5280` 生成另一价格侧，并通过 `+1726A10`、`+1726AF0` 做上下界限制，最后按方向求差。

本轮不在暂停现场调用这些函数，也不单步进入它们，因此只能新增以下保守结论：

```text
本地/州相关价格函数 +1408330
    ↓
13A3280 / 13A3B10 / 13A5280 组合价格或优势修正
    ↓
1726A10 / 1726AF0 上下界限制
    ↓
按 direction 求价差
    ↓
单位净收益 p 的输入之一
```

这补齐了第四节中“调用链顺序”的证据，但没有把中间函数的槽位伪命名成国内价格、世界价格或关税。已有分析对 `A`、`P` 的解释仍应保持“高可信推测”，不能升级成逐位确认。

### 2. 字段级标注：`+0x1D58` / `+0x1D5C` 可作为待验证对象字段

建议在第四节新增如下记录：

```text
在 +11FD5BB…+11FD5D0，Refresh/执行前置路径从 r14 指向对象读取：
    int32 field_1D5C -> [rsp+0x330]
    int32 field_1D58 -> [rsp+0x50]
当前现场 R14=3A484D9DB60；两个读取地址分别为 3A484D9F8B8 和 3A484D9F8B8? 
```

上面第二个地址应严格计算为：

```text
field_1D58 = 3A484D9DB60 + 1D58 = 3A484D9F8B8
field_1D5C = 3A484D9DB60 + 1D5C = 3A484D9F8BC
```

它们是 32 位相邻字段。字段值本身在当前断点现场尚未读取，因为用户明确要求保持断点，且本轮采集重点是避免对数据断点产生额外访问副作用。后续若用户允许只读内存读取，可读取这两个字段并与同一对象的候选快照对照，但仍需结合写入来源才能命名。

### 3. 评分合成顺序可以进一步收紧

根据当前位置和已有 `+11FC320` 导出，评分链可以分成三个阶段：

```text
A. 候选上下文准备
   +11FD370 构造 [rsp+0x60] 临时上下文
   条件性调用 +11FDBDA0 更新/解析状态

B. 候选对象字段读取
   [r14+0x1D5C] -> [rsp+0x330]
   [r14+0x1D58] -> [rsp+0x50]
   这两个值参与后续评分或资格路径

C. 评分合成与写回
   +11FC080 计算基础收益 R=q×p
   +11FC320 检查数量限制并合成 D
   写入候选评分字段 +0x20
```

因此第四节的目标不应写成“只缺价格函数”，还缺少 `r14` 对象字段到评分临时槽位的精确语义映射，以及这两个字段是否在 `+11FC320` 进入某一条分支。

## 三、当前不能确认的部分

1. `[r14+0x1D58]` 的正式字段名、单位和符号解释不能由 `mov` 指令单独确定。
2. `[r14+0x1D5C]` 与 `[r14+0x1D58]` 是否分别代表税率、补助、贸易优势、价格上下界或某个状态标志，当前没有充分证据。
3. 两个非模块断点地址与字段读取地址相同，说明它们是数据地址；但仅凭断点列表不能确认断点类型是写入断点还是访问断点，也不能确认触发顺序。
4. 当前 RIP 位于函数执行中段；在不继续执行、不命中后续指令的情况下，不能取得本次候选的最终 `D`、`D-R` 分项或价格函数返回值。
5. 不应把本轮的现场数据用于声称“任意样本可以逐位计算”。仍需多样本、价格函数、字段来源和边界分支证据。

## 四、推荐的下一次采集顺序

在用户明确允许继续保持当前断点策略后，优先级建议如下：

1. 仅读取 `r14+0x1D58`、`r14+0x1D5C` 和候选基址相关内存，记录原始十六进制值；不读取或修改代码断点。
2. 从磁盘/静态反汇编展开 `+11FD370`、`+11FDBDA0`、`+11FC320` 的完整控制流，并将 `[rsp+0x50]`、`[rsp+0x330]` 的后续使用点标出来。
3. 展开 `+1408330`、`+13A3280`、`+13A3B10`、`+13A5280` 的静态函数图；优先追踪调用参数、返回寄存器和定点缩放，不运行游戏函数。
4. 若要收集 `D-R` 分项，先保存一个断点现场快照，再在同一候选上获取完整状态；每次采集后核对 RIP、RSP、寄存器和数据断点列表。
5. 最后才做增加/减少、进口/出口的多样本对账；不要用一次现场的 `+0x1D58` 值替代价格、关税或补助的正式字段定义。
