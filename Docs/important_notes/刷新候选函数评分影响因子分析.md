# 刷新候选函数评分影响因子分析

本文回答 `Docs\important_notes\todo.md` 的第一个问题：刷新候选函数的整体评分受哪些因素影响，以及当前证据能把这些因素确认到什么程度。

分析入口是 `victoria3.exe+11FBDA0`（分析命名为 `Refresh`），尾部跳转到 `+11FC320` 合成最终评分。候选对象中，`+38` 是单次容量对应的商品量 `q`，`+18` 是单位净收益 `p`，`+10` 是基础收益 `R`，`+20` 是最终评分 `D`，`+30` 是短缺指标 `H`，`+40` 是贸易优势相关缓存。

## 结论先行

当前可以确认，评分不是只读取一个“贸易优势”字段，也不是只比较单位利润。主干关系是：

```text
q = 单次容量对应的商品量
p = 模拟当前候选后的单位净收益
R = trunc(q × p)
D = R + 政策修正 + 反方向贸易修正 + 短缺修正
```

从游戏观测数据推测，p 大概率是 f（（本地市场价格 - 国际市场价格 + 进出口补贴 - 关税），相对优势）

在数量限制不失败的常用路径中，现有反汇编可读成近似公式：

```text
D ≈ R
   - 25 × max(有效关税率, 0)
   + 补助差额评分
   - 1000 × 反方向市场份额
   + 300 × H
```
H:短缺指标
反方向市场份额 = 当前本地市场的反方向数量/世界市场的反方向数量

若D是进口评分，则和本地市场出口份额/世界出口份额成负相关。本地市场出口占比越高，则越不需要进口。

这些值使用 `100000` 定点整数，实际每一步分别截断。增加候选和减少候选共用评分框架，但模拟上下文不同：增加会先模拟加入 `q` 后的市场，减少收益使用当前贸易，减少的短缺计算则模拟移除 `q`。

## 一、已经能确认的内容

### 1. 评分字段和计算顺序

`+11FBDA0` 先解析州和商品，再写入 `c+38` 的 `q`，读取或计算 `c+40` 的绝对贸易优势，随后计算短缺和收益，最后由 `+11FC320` 写 `c+20`。

`+11FC080` 读取 `c+38` 和 `c+18`，将两个五位小数定点整数相乘并除以 `100000`，写入 `c+10`。已保存的两个候选快照逐位复算一致：

```text
R = trunc(Q × P / 100000)
```

所以基础收益是“一次容量单位对应的商品量 × 单位净收益”，不是整条贸易的总收益。

### 2. 数量限制可以直接使评分失效

`+11FC320` 先读取世界反方向数量、市场反方向数量和本地方向数量。数量关系不满足限制时，候选评分被写成 `INT64_MIN`，候选不能正常参与增加或减少。

“世界反方向数量”和“市场反方向数量”是评分函数 +11FC320 做数量限制和反向贸易扣分时使用的两个统计量。
假设当前候选是进口：
- 当前方向：进口
- 反方向：出口
- 世界反方向数量：全局贸易统计中该商品的出口数量，并加上上下文中的相关临时数量。
- 市场反方向数量：当前市场中该商品的出口数量，并加上当前候选计算上下文中的相关数量。

现有资料将这条限制概括为：本地方向量不能超过由世界反方向量减去市场反方向量形成的可承接量的两倍。倍数和字段读取位置有反汇编支持，但这些表的正式业务名称仍未完全恢复。

**在进口情况下则是：本地进口 <= 2*(世界出口量 - 本地出口量)**

### 3. 关税、补助、反方向份额和短缺都会影响 `D`

- 有效关税率为正时，评分额外减去关税评分项，当前恢复的系数为 `25`。
- 本方向补助与反方向补助先形成差额，再按评分系数加入；正差额在特定进口且供给不足的条件下会放大 `20` 倍。
- 世界和市场反方向贸易份额会形成扣分，当前恢复的评分系数为 `1000`。
- 短缺指标 `H` 会形成加分，当前恢复的系数为 `300`。短缺只在方向 `0` 的有效市场商品路径计算；方向 `1` 写零。

“增加”与“减少”都用同一评分合成函数，但减少短缺会把供给先减去 `q`，因此移除后才出现短缺时，减少候选可能得到更高的保留评分。

### 4. 候选选择和执行门槛也会影响实际结果

评分本身与随机选择扰动不同。减少选择函数寻找较低评分，增加选择函数寻找较高评分；增加候选还要通过增加门槛，普通模式通常为 `50`，减少维护门槛通常为 `25`。容量已满时，替换还要求新评分严格大于旧评分的两倍。初始化模式会把相关门槛乘 `0.75`。

执行函数会再次 `Refresh`，所以选择阶段的随机扰动评分不是最终写回的原始评分。即使评分已算出，也可能因容量、资格、保护期或门槛而不执行。

### 5. 贸易优势的作用边界

`c+40` 是正的绝对贸易优势相关缓存。`+11FBDA0` 的调用链使用方向表、商品对象、州/市场对象和 `TRADE_FRACTION` 上下文，并在缓存写回前设置至少 `100000` 的定点下限。该字段不是已证明的 UI 相对优势百分比，也没有证据表明它直接作为一项加数写入 `D`。

因此，贸易优势会通过价差或收益计算链间接影响 `p` 和 `R`，不能把 `c+40` 直接再加到最终评分。

## 二、大概率可从现有信息推测的内容

### 1. 评分的经济含义

评分表示“保留或扩张该方向贸易的吸引力”。增加选择高分，减少选择低分；减少评分不是“减少能赚多少”的负数。这个解释与选择函数的排序、执行门槛及官方关于利润、关税、补助和短缺的说明一致。

### 2. 单位净收益的价差来源

`p` 很可能由方向相关的本地/市场价格差、有效关税和本方向补助组成。已展开的函数支持“价差先计算，再将税补折算为净收益”的数据流；将价差两端分别命名为国内价格和世界/进口价格是高可信解释，但不能把它等同于界面显示的两个裸价格。

### 3. 补助和关税的双重作用

本方向补助和关税已经进入 `p`，同时又在 `D` 中作为行为偏好修正出现。因此它们很可能既改变实际利润，也独立改变 AI 的贸易意愿。反方向补助主要出现在评分差额项，不能据此断言它参与本方向单位净收益。

### 4. 反方向份额抑制过度集中

评分中的市场反方向份额扣分很可能用于避免同一商品同时大量进行相反方向贸易。当前公式、方向表和执行时更新的多套统计表都支持这一解释，但“反方向份额”具体是州、市场还是世界口径，仍要以完整表结构为准。

### 5. 短缺奖励的形状

短缺函数将供需比转换为有上限的短缺指标，供需比越低，`H` 越高；评分再乘 `300`。方向 `0` 的特殊路径大概率是进口补充本地短缺。现有资料已经给出若干供需比到 `H` 的样例，但不能把样例外推成所有边界条件的完整经济定义。

## 三、不确定性较高的内容

### 1. `+D16160` 和 `+D18B90` 中各中间槽位的正式字段

已知它们构造州/市场、商品、方向和 `TRADE_FRACTION` 的定点上下文，也已知 `+EB2350` 进行定点插值/组合；但不能唯一确定每个栈槽对应生产量、消费量、贸易中心等级、市场份额、兴趣、协定或其他修正中的哪一项。

因此不能把贸易优势写成已经证实的简单公式，例如：

```text
州生产占比 × 市场贸易份额
```

更稳妥的说法是：它是影响价格差和收益的方向相关绝对优势计算链。

### 2. 价差和有效价格的完整公式

`+1408330` 等函数的调用关系支持方向价差，但内部价格曲线、优势如何改变有效世界价格、边界和舍入尚未全部展开。当前可确认评分结构，不能从任意商品 UI 数字逐位重建 `p`。

### 3. 某个样本的 `D-R` 应归因于哪一项

快照中木材 `D-R=16.21`、艺术品 `D-R=0` 可以准确相减，但尚未读取该样本的有效税率、补助率和反方向份额逐项重算。因此不能把 `16.21` 全部归因于补助，也不能把艺术品的零差值解释为每一项都为零；分项可能互相抵消。

### 4. 方向枚举的正式名称

方向 `0` 对应进口、`1` 对应出口是高可信解释，短缺奖励和世界需求缓冲都与之吻合，但仍缺少独立的有符号枚举/字段注册证据。严谨记录时应保留数字方向，并把中文方向名称标为推测。

### 5. 某些配置常量是否在更深层使用

`AUTONOMOUS_TRADE_POTENTIAL_REVENUE_BASE_COST_FACTOR=0.25` 未在已展开的评分主体中识别到直接使用。不能因为它与相关配置相邻，就擅自把基础收益再除以 `0.25`；更深层收益函数是否使用它仍未确认。

## 四、缺失的信息和需要的证据

要把评分从“结构已恢复”推进到“任意样本可逐位计算”，还缺少：

1. 完整导出 `+1408330`、`+13A3280`、`+13A3B10`、`+13A5280` 及其调用的价格函数，确认优势、国内价格、世界价格、税和补助的精确顺序。
2. 对 `+D16160`、`+D18B90` 内部辅助调用做字段级标注，将定点槽位映射到游戏对象属性和脚本定义。
3. 同一州、同一商品分别构造增加/减少、进口/出口样本，读取有效关税、补助、价格、供给、需求和反方向份额，并与 `D-R` 逐项对账。
4. 导出数量限制读取函数，确认世界、市场和本地方向三个表的精确口径及边界处理。
5. 追踪 UI 相对贸易优势的格式化调用点，建立 `c+40` 的绝对值与 UI 百分比之间的换算关系。
6. 对负数、零供给、最小交易量、整数溢出和初始化模式分别采集样本，验证当前常用路径公式之外的分支。

## 当前回答的边界

可以确认的是：评分以 `R=q×p` 为主干，并叠加关税、补助差额、反方向份额和短缺等修正，最后受数量限制和门槛控制。可以高概率解释这些修正的经济用途。尚不能确认的是完整价格/优势公式、每个中间槽位的正式字段以及任意输入到最终 `D` 的逐位结果。后续分析应优先补齐上面的价格函数和字段级样本。
